Política de Privacidade

GTA 6 Viral Shorts Bot
Última atualização: 26 de novembro de 2026
Versão: 1.0

1. Introdução

Esta Política de Privacidade descreve como o GTA 6 Viral Shorts Bot ("nós", "nosso", "o Bot") coleta, usa, armazena e protege suas informações quando você utiliza nossa ferramenta de criação e publicação automática de clipes verticais para TikTok, Instagram Reels e YouTube Shorts.

Ao usar o Bot, você concorda com as práticas descritas nesta política. Se não concorda, por favor, não utilize o Bot.

2. Responsável pelo Tratamento de Dados

Contato: Via GitHub Issues

3. Dados Coletados

O Bot opera localmente na sua máquina e não envia dados para servidores nossos. Coletamos apenas o necessário para funcionar:

3.1 Tokens de Autenticação OAuth (TikTok)

  • Access Token — usado para chamadas à API de upload de vídeo
  • Refresh Token — usado para renovar o access token automaticamente
  • Escopo: video.upload, user.info.basic

3.2 Metadados de Vídeo (Fornecidos por Você)

  • Títulos, descrições, hashtags para publicação
  • Configurações de privacidade do vídeo (público/privado/amigos)
  • Timestamps de cortes selecionados

3.3 Logs de Processamento (Locais)

  • Status de processamento (sucesso/erro)
  • Timestamps de início/fim de cada etapa
  • Códigos de erro da API (para debug)

5. Armazenamento e Segurança

5.1 Armazenamento Local Apenas

Todos os dados ficam exclusivamente no seu dispositivo (arquivos locais). Não usamos banco de dados na nuvem, nem servidores próprios.

5.2 Criptografia

  • Tokens OAuth armazenados com criptografia AES-256
  • Chave de criptografia derivada da sua máquina (não armazenada)

5.3 Retenção

  • Tokens: Até você revogar (via TikTok App Settings) ou expirarem
  • Logs: 30 dias (limpeza automática)
  • Metadados de vídeo: Apenas durante o processamento ativo

6. Compartilhamento de Dados

Não vendemos, alugamos ou compartilhamos seus dados com terceiros.

Os únicos destinatários são as APIs oficiais do TikTok (via api.tiktok.com) para:

  • Autenticação OAuth (oauth/token)
  • Upload de vídeo (video/upload)
  • Informações básicas do usuário (user/info)

Essas chamadas seguem os Termos de Serviço da API do TikTok e a Política de Privacidade do TikTok.

7. Seus Direitos (LGPD / GDPR)

Como os dados ficam no seu dispositivo, você tem controle total:

  • Acesso: Veja todos os arquivos locais do Bot
  • Retificação: Edite/atualize tokens e configurações a qualquer momento
  • Exclusão: Delete a pasta do Bot → todos os dados somem
  • Revogação: No TikTok: Configurações → Segurança → Apps conectados → Remover
  • Portabilidade: Seus arquivos de configuração são JSON/texto simples

8. Cookies e Rastreamento

O Bot não usa cookies, pixels, fingerprinting, analytics ou qualquer forma de rastreamento. Não há interface web — é uma ferramenta de linha de comando (CLI) local.

9. Serviços de Terceiros

O Bot pode usar estas bibliotecas/serviços locais (rodam na sua máquina):

  • FFmpeg — processamento de vídeo (local, sem rede)
  • Whisper (OpenAI) — transcrição de áudio (local via Ollama, sem rede)
  • Ollama — LLMs locais para geração de títulos/hashtags (local, sem rede)

Nenhum dado de vídeo/áudio sai da sua máquina para esses serviços.

10. Conteúdo de Terceiros (GTA 6 / Rockstar Games)

O Bot processa gameplay footage de GTA 6. Você é responsável por:

  • Ter direitos sobre o gameplay gravado
  • Cumprir as Diretrizes de Conteúdo da Rockstar Games
  • Não incluir música/áudio protegido por copyright nos clipes

11. Menores de Idade

O Bot não é direcionado a menores de 13 anos (ou 16 no Espaço Econômico Europeu). Não coletamos intencionalmente dados de menores. Se você é pai/mãe e acredita que seu filho nos forneceu dados, entre em contato para exclusão imediata.

12. Transferência Internacional

Os tokens OAuth trafegam para os servidores do TikTok (EUA/Singapura/outros). O TikTok é certificado sob EU-US Data Privacy Framework e UK Extension. Não há transferência para nossos servidores (não temos).

13. Alterações nesta Política

Podemos atualizar esta política. Notificaremos via:

  • Release notes no GitHub
  • Mensagem no terminal ao executar o Bot (se aplicável)

O uso contínuo após alterações constitui aceitação.
